# Faka Pomodoro

Timer Pomodoro sederhana berbasis web untuk membantu manajemen waktu belajar/kerja menggunakan teknik Pomodoro.

## Fitur

- **Pomodoro (25 menit)** — sesi fokus utama
- **Short Break (5 menit)** — istirahat singkat antar sesi
- **Long Break (15 menit)** — istirahat panjang setelah beberapa sesi
- Tampilan timer digital dengan tema warna berbeda untuk tiap mode
- Tombol Start/Pause dan Reset

## Cara Pakai

1. Buka file `timerpomodoro.html` langsung di browser, atau akses via GitHub Pages (jika sudah diaktifkan).
2. Pilih mode (Pomodoro / Short Break / Long Break).
3. Klik **START** untuk memulai hitung mundur.
4. Klik **PAUSE** untuk menjeda, atau **RESET** untuk mengulang dari awal mode yang dipilih.
5. Notifikasi akan muncul saat waktu habis.

## Teknologi

- HTML, CSS, dan JavaScript murni (vanilla), tanpa framework atau library eksternal.
- Font [Poppins](https://fonts.google.com/specimen/Poppins) dari Google Fonts.
